# Plataforma de mascotas

Un perfil digital único para cada perro o gato, que le pertenece a su dueño: se actualiza apenas ocurre cada vacuna, consulta o examen, y se muestra o se envía en segundos a cualquier veterinario, cuidador o guardería, sin que esa persona necesite una cuenta.

> *"Que la salud de tu mascota nunca dependa de dónde quedó el papel."*

**Lenguajes Digitales 5 — Universidad El Bosque** · Samuel Parada y Andrés Claros

---

## Cómo está organizado

El proyecto sigue Spec-Driven Development con Spec Kit, según la guía del curso.

| Carpeta | Qué hay | Quién la escribe |
|---|---|---|
| `docs/` | Brief, discovery, sistema de diseño, referencias, flujo de pantallas y hoja de ruta SDD | El equipo |
| `.specify/` | Configuración de Spec Kit y la constitution (`memory/constitution.md`) | Spec Kit |
| `.claude/` | Los comandos `/speckit-*`, instalados como Skills de Claude Code | Spec Kit |
| `specs/` | Una carpeta por feature: spec, plan, modelo de datos, quickstart y tareas | Spec Kit |

`.specify/`, `.claude/` y `specs/` van apareciendo a medida que se avanza en las fases.
