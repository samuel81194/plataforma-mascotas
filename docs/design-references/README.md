# Referencias de diseño

Carpeta para capturas, mood boards y ejemplos que inspiran o informan el diseño. Git no versiona carpetas vacías: por eso existe este archivo.

## Cómo usarlas con Claude

- Arrastren la imagen directo al chat cuando pidan algo de diseño, o
- refiéranse a una ya subida: `@docs/design-references/archivo.png`

## Cómo nombrarlas

`tema_fuente_descripcion.png` — por ejemplo, `vista-rapida_iphone-ficha-medica.png` o `pdf_laboratorio-resultado-hemograma.png`.

## Qué buscar

| Para diseñar… | Referencias útiles |
|---|---|
| Vista de acceso rápido | La ficha médica de emergencia del iPhone (app Salud) y la información de emergencia de Android: resuelven el mismo problema —alergias y medicamentos a la vista— para personas |
| Registro en menos de un minuto | Apps que registran algo con una foto y pocos campos: gastos, recibos, notas rápidas |
| Historial | Apps de salud o de banca con listas agrupadas por fecha y filtros |
| Reporte PDF | Carnets de vacunación reales, resultados de laboratorio, resúmenes de historia clínica |
| Competencia | Apps de historial de mascotas: busquen "historial mascota" y "pet health record" en las tiendas de apps |
| Pantallas de Figma | Exportaciones o capturas de lo que diseñen en Figma |

## Privacidad

Antes de subir fotos de carnets, fórmulas o exámenes reales, **tapen el nombre, la cédula, el teléfono y la dirección del propietario** (Ley 1581 de 2012). El repositorio no es lugar para datos personales de terceros.
